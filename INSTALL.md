# Install Stagecraft 1.0.0

Inspect this archive, then copy music-video-production into your Codex skills directory (normally $CODEX_HOME/skills or ~/.codex/skills). Preserve any existing local modifications before replacing an installation.

Invoke $music-video-production in a new task with your song, references, tools and budget. Read SKILL.md first. The Python helpers need Python 3.11+; the sampler also needs FFmpeg/ffprobe. These tools do not include vendor access or authority to spend, publish or create scheduled work.

Code and documentation: MIT. Educational example media: see music-video-production/NOTICE.md.
